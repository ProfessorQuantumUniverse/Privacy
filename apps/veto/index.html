1. What this app does

Veto is an open source VirusTotal client for Android. You can submit a file, a link or one of your installed apps to the VirusTotal service, follow the analysis in real time and read the report – from a single verdict down to every field the service returns. You use your own free VirusTotal API key, so every scan runs under your own VirusTotal account and goes directly from your device to VirusTotal.

The app is Free and Open Source Software (FOSS), developed as a private, non-commercial hobby project. It contains no ads, no in-app purchases and no accounts of its own.

2. No data collection

This app collects, stores, shares or transmits NO personal data or sensitive user information to the developer.

The developer operates no server, no user account system and no database, so there is no place where personal data about you could be stored. Veto has no „phone home“ of any kind. Specifically, the app does not collect:

  • Your name, e-mail address, phone number or any other contact information.
  • Your device's unique identifiers (Device ID, Advertising ID, IMEI, etc.).
  • Your precise or approximate location.
  • Your contacts, calendars, messages or call logs.
  • The list of apps installed on your device.
  • Your files, your scan history or the content of your clipboard.
  • Your VirusTotal API key.
  • Usage analytics, behavioural profiles, crash reports or telemetry of any kind.

This matches the „Data safety“ declaration of this app on Google Play: no data collected, no data shared with third parties.

3. Data that stays on your device

The following is stored in the app's private storage area on your device only (Android DataStore):

  • Your VirusTotal API key – encrypted (see section 6).
  • Reports you choose to save, so you can open them again later, even offline.
  • Your app settings, for example the report mode and whether help notes are shown.

When you scan a file you picked, the app makes a temporary copy in its private cache so it can calculate the file's hash and upload it if necessary. This copy is deleted as soon as the scan is finished.

None of this is ever transmitted to the developer. Clearing the app's data or uninstalling the app removes everything completely. If you have enabled Android's own device backup, Android may include your saved reports and settings in your personal backup; your API key is explicitly excluded from cloud backup and from device-to-device transfer.

4. Internet connections and third parties: VirusTotal

Veto talks to exactly one service: the official VirusTotal API (www.virustotal.com), and only when you start a scan yourself. The connection goes directly from your device to VirusTotal over HTTPS, authenticated with your own API key – never through a server of the developer. What is sent depends on what you scan:

  • Files and installed apps: the app first sends only the file's SHA-256 hash to look up an existing report. Only if VirusTotal does not know the file yet is the file itself (for an installed app: its APK) uploaded for analysis.
  • Links: the URL you enter, paste or share to Veto is submitted to VirusTotal.

VirusTotal (a service of Google) necessarily receives technical connection data such as your IP address, your API key (which identifies your VirusTotal account) and the item you submitted, and processes them under its own terms and privacy policy – see the VirusTotal Privacy Policy and the VirusTotal Terms of Service. The developer has no access to anything you submit and cannot see what you scan.

Please note: according to VirusTotal's terms, files and URLs submitted to VirusTotal may be shared with the security community, antivirus partners and VirusTotal's premium customers. Do not upload documents that contain personal, confidential or sensitive information (for example contracts, ID scans or private photos). For such files a hash lookup is usually the safer option. This is how VirusTotal works and is outside the control of this app.

Apart from VirusTotal, the app makes no network connections at all. It contains no advertising, no analytics SDK, no crash reporter, no in-app purchases and no tracking of any kind. Links such as „Get an API key“ or „Open on VirusTotal“ open in your own browser only when you tap them.

5. Permissions

  • Internet access – to reach the VirusTotal API.
  • Query all packages – to show the list of apps installed on your device so that you can pick one to scan. The list is built and shown only on your device; it is never sent anywhere. Only the app you actively select is hashed and, if necessary, uploaded.
  • Post notifications – to show scan progress and the notification when a result is ready.
  • Foreground service (data sync) – to keep a running scan alive while the app is in the background.
  • Vibrate – for haptic feedback.

Clipboard: when you open the app, Veto checks locally whether your clipboard contains a web link, so it can offer a „Scan this link“ shortcut. The clipboard content is only evaluated on your device and is never sent anywhere unless you tap the shortcut. Android may display a short system notice when an app reads the clipboard – this is that check.

Sharing to Veto: if you share a link to Veto from another app, Veto starts a scan of that link, because that is the action you requested.

6. Security

Because Veto handles a credential (your API key) and potentially sensitive files, security was built in from the start:

  • Encrypted API key. Your VirusTotal API key is encrypted with an AES-256-GCM key held in the Android Keystore. That key never leaves the Keystore, so the stored value is useless outside your device.
  • Key stays on your device. The key is only ever used to authenticate your own requests to VirusTotal. The settings store containing it is excluded from cloud backup and from device-to-device transfer, so it is never copied anywhere else. On a new device you simply enter the key again.
  • HTTPS only. Unencrypted (cleartext) network traffic is disabled for the whole app. All communication with VirusTotal is encrypted in transit.
  • No developer server. There is no backend that could be hacked, leak data or be forced to hand over data – because none exists.
  • No logging of secrets. Network logging exists only in debug builds and redacts the API key header; release builds from Google Play do not log network traffic.
  • Android app sandbox. All app data lives in the app's private storage, inaccessible to other apps. Temporary file copies are deleted right after the scan.
  • Least privilege. The app requests only the permissions listed above and no access to your location, contacts, camera, microphone or storage beyond the files you explicitly pick.
  • No third-party SDKs that collect data. The app is built only from open source libraries (AndroidX/Jetpack, Kotlin, Retrofit, OkHttp, Hilt).
  • Public, reviewable code. Every change is visible in the public Git history and checked by automated builds (GitHub Actions).

Found a security issue? Please report it confidentially by e-mail to makerlab.fffm+google-play@gmail.com. Reports are taken seriously and fixed as quickly as possible.

7. Children

The app is safe for all age groups from a data protection point of view: since no personal data is collected at all, no data of children can be collected either. There is no user-generated content, no chat and no advertising. The use of VirusTotal itself is subject to VirusTotal's terms.
